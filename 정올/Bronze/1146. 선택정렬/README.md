문제
 한국어


선택 정렬(selection sort)이란 내부정렬 알고리즘의 하나로 다음 순서대로 실행하여 정렬을 한다.

주어진 수열 중에 최소값(같은 값이 여러 개 있는 경우 처음 값)을 찾는다.

찾은 최소값을 맨 앞의 값과 자리를 바꾼다.

맨 앞의 값을 뺀 나머지 수열을 같은 방법으로 전체 개수-1번 반복 실행한다.

 n개의 주어진 수열을 위와 같은 방법으로 정렬한다.

 

수열이 주어지면 선택정렬의 과정을 한 단계씩 출력한다.​ 


입력
첫줄에 수열의 길이 
N
(
4
≤
N
≤
100
)
N(4≤N≤100)이 주어진다. 두 번째 줄에 
N
N개의 0이상 100이하의 정수가 주어진다.


출력
처음 상태를 제외하고 정렬과정의 각 단계별 결과를 "출력형식"과 같이 출력한다.


예제
입력
5 
6 4 8 3 1

출력
1 4 8 3 6 
1 3 8 4 6
